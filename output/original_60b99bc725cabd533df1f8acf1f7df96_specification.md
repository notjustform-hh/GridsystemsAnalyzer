# Layout Specification: Interview Magazine Double-Page Spread

## 1. Format & Proportions
- **Orientation**: Landscape spread
- **Aspect Ratio**: 1.56:1 (overall spread)
- **Page Ratio vs φ**: 1.56 (φ = 1.618) ✓ 96% proximity to golden ratio
- **Assumed Format**: Magazine spread, likely 11×8.5" or similar editorial format
- **Spread or Single**: Double-page spread with central spine

## 2. Margins
- **Top**: 30px (3.3%)
- **Right/Outer**: 30px (2.1% per page)
- **Bottom**: 30px (3.3%)
- **Left/Inner**: 30px (2.1% per page)
- **Gutter**: 20px (1.4%) central spine separation
- **Symmetry**: Symmetrical margins across spread - contemporary magazine approach
- **Notes**: Minimal 30px margins maximize content area for dramatic photographic impact

## 3. Grid System
- **Grid Type**: Horizontal division with multi-column text grid
- **Column Count per Page**: 3 text columns per page below photo area
- **Total Columns (spread)**: 6 text columns across spread
- **Column Widths**: 160px each (23.9% per page) in text area
- **Column Width (px)**: Text area: 160px × 6 columns with 20px gutters
- **Gutter Width**: 20px between columns, minimal spine
- **Row/Zone Structure**: Header(50px) | Photo(440px) | Text(360px)
- **Baseline Grid**: Implied grid for text alignment
- **Compound Grid**: Yes - photo area spans full width, text uses columnar system
- **Confidence**: High
- **Reasoning**: Clear horizontal photo/text division at 60/40 ratio, consistent column structure in text area

## 5. Visual Hierarchy
1. **Primary**: Repeated portrait photography - dominates 60% of spread area
2. **Secondary**: Header text elements - publication identity and article title
3. **Tertiary**: Body text in 6-column grid - supporting editorial content
4. **Reading flow**: Headers → Photography (left to right scan) → Text columns → Spine credit

## 6. Spacing & Proportional System
- **Dominant spacing unit**: 20px (column gutters) and 30px (margins)
- **Golden ratio presence**: Strong - 60/40 photo/text division closely matches φ proportions
- **Vertical rhythm**: Clean horizontal bands - 50px header, 440px photo, 360px text
- **Density**: Medium density with 60% photographic content, 40% text/white space
- **White space strategy**: Minimal margins maximize dramatic photo impact, text breathing room via column structure

## 7. Typography Observations
- **Heading scale**: Small header text maintains editorial sophistication vs photo impact
- **Body text columns**: 6-column system provides readable measure and flexible layout
- **Type scale**: Consistent sans-serif hierarchy, no dramatic scaling
- **Alignment**: Clean left-aligned text, centered headers
- **Special typography**: Vertical spine text adds editorial design sophistication

## 8. Design Principles Detected
- **Photography as hero element**: 60% allocation creates visual impact and photographer focus
- **Editorial restraint**: Typography remains supportive, not competitive with photography
- **Repetition as pattern**: Nine portrait repetitions create rhythm and visual texture
- **Professional magazine layout**: Balance of visual drama with text readability
- **Horizontal emphasis**: Strong landscape orientation emphasizes spread format
- **Contemporary editorial design**: Clean, minimal approach with maximum photo impact

## 9. Responsive Adaptation Notes
The dramatic horizontal photo/text division will collapse on mobile, fundamentally altering the design's impact. The 60% photographic area that creates the spread's visual power will be compressed, losing the cinematic quality of the repeated portraits spanning the full width. The 6-column text grid will stack vertically, eliminating the sophisticated editorial layout that balances readability with visual rhythm. The vertical spine typography will likely be repositioned or eliminated, losing an important editorial design element. Most critically, the spread experience of seeing nine portraits simultaneously across the full width will be reduced to a scrollable sequence, fundamentally changing the visual impact from pattern recognition to sequential viewing. Consider maintaining the portrait repetition as a horizontal scroll element on mobile to preserve some of the original pattern effect while accepting the loss of the dramatic scale that defines the spread experience.
