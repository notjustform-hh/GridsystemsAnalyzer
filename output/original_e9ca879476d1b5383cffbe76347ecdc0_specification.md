# Layout Specification: Typography Specimen - Axis & FP Clifford Comparison

## 1. Format & Proportions
- **Orientation**: Landscape spread
- **Aspect Ratio**: 1.5:1
- **Page Ratio vs φ**: 1.5 (φ = 1.618) ✓ 93% proximity to golden ratio
- **Assumed Format**: Typography specimen magazine, likely A4 landscape or custom editorial format
- **Spread or Single**: Double-page spread with central spine for direct font comparison

## 2. Margins
- **Top**: 30px (2.5%)
- **Right/Outer**: 30px (1.7% per page)
- **Bottom**: 30px (2.5%)
- **Left/Inner**: 30px (1.7% per page)
- **Gutter**: 60px (3.3%) central spine separation
- **Symmetry**: Perfect symmetrical margins for comparative analysis
- **Notes**: Consistent 30px margins frame the educational typography content

## 3. Grid System
- **Grid Type**: Bilateral symmetric comparison layout
- **Column Count per Page**: Left: specimen + character grid | Right: mirrored specimen + character grid
- **Total Columns (spread)**: 4 main zones per page (specimen, character sets, sample text, descriptions)
- **Column Widths**: Specimen areas: 320px (17.8%) | Character/sample areas: 340px (18.9%)
- **Column Width (px)**: Left page: 320px + 340px | Right: 320px + 340px (mirrored)
- **Gutter Width**: 30px between specimen and character areas, 60px central spine
- **Row/Zone Structure**: Header(30px) | Specimen area(360px) | Sample text(180px) | Descriptions(480px) | Footer(30px)
- **Baseline Grid**: Typography specimen alignment for character display
- **Compound Grid**: Yes - large specimen display with systematic character grid overlay
- **Confidence**: High
- **Reasoning**: Perfect bilateral symmetry for direct font comparison, mirrored structure

## 5. Visual Hierarchy
1. **Primary**: Large specimen letterforms - "aget ags" (Axis) and stylized sample (FP Clifford)
2. **Secondary**: Character set displays showing complete alphabets and numerals
3. **Tertiary**: Sample text demonstrating fonts in editorial context
4. **Quaternary**: Technical descriptions and design process documentation
5. **Reading flow**: Left specimen → Right specimen → Character sets → Sample text → Technical descriptions

## 6. Spacing & Proportional System
- **Dominant spacing unit**: 30px (margins and gutters) and 60px (central spine)
- **Golden ratio presence**: Strong - spread ratio approaches φ, specimen positioning follows golden section
- **Vertical rhythm**: Header (30px) + Specimen (360px) + Sample (180px) + Body (480px) + Footer (30px)
- **Density**: Balanced - equal information density on both pages for fair comparison
- **White space strategy**: Ample breathing room allows focus on letterform details and characteristics

## 7. Typography Observations
- **Specimen scale**: Large letterform displays emphasize character details and proportions
- **Character sets**: Systematic presentation of complete alphabets for comparison
- **Sample text**: Contextual demonstration showing fonts in actual use scenarios
- **Technical descriptions**: Small body text providing design methodology and technical specifications
- **Alignment**: Centered specimen displays, left-aligned technical text
- **Comparison methodology**: Mirrored layout enables direct visual comparison of font characteristics

## 8. Design Principles Detected
- **Educational comparison**: Bilateral symmetry enables direct font analysis
- **Typography as subject**: Fonts themselves are the primary content and focus
- **Systematic presentation**: Complete character sets demonstrate letterform relationships
- **Professional specimen format**: Industry-standard typography documentation approach
- **Designer attribution**: Akira Kobayashi credit emphasizes expert curation
- **Visual methodology**: Layout design supports comparative typography analysis

## 9. Responsive Adaptation Notes
The bilateral comparison that defines this educational layout will be fundamentally compromised on mobile devices. The side-by-side specimen displays that currently enable direct font comparison will stack vertically, breaking the visual relationship that allows immediate letterform analysis. The character set grids will lose their comparative positioning, making it difficult to assess relative proportions and characteristics. The sample text areas will stack below specimens, eliminating the integrated comparison that demonstrates fonts in context. Most critically, the simultaneous visual comparison that enables typography education will be lost, converting this from a comparative analysis tool into sequential font presentations. The mirrored layout structure that supports professional typography specimen methodology will collapse to linear content flow. Consider creating tabbed interfaces or overlay comparisons to maintain some comparative functionality, while accepting that the sophisticated bilateral analysis approach will be simplified to individual font presentations.
