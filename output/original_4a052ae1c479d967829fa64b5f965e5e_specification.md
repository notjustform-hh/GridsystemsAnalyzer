# Layout Specification: NewWork Magazine Willi Kunz Black Spread

## 1. Format & Proportions
- **Orientation**: Landscape spread
- **Aspect Ratio**: 1.46:1
- **Page Ratio vs φ**: 1.46 (φ = 1.618) ✓ 90% proximity to golden ratio
- **Assumed Format**: Magazine designer profile spread, likely A3 or custom format
- **Spread or Single**: Double-page spread with minimal central spine

## 2. Margins
- **Top**: 40px (3.1%)
- **Right/Outer**: 40px (2.1% per page)
- **Bottom**: 40px (3.1%)
- **Left/Inner**: 40px (2.1% per page)
- **Gutter**: 40px (2.1%) minimal central spine
- **Symmetry**: Symmetrical margins with asymmetric content organization
- **Notes**: Consistent 40px margins provide clean frame for high-contrast editorial content

## 3. Grid System
- **Grid Type**: Asymmetric editorial layout with systematic column structure
- **Column Count per Page**: Left: single zones | Right: 4-column text system
- **Total Columns (spread)**: 6 zones (logo, name, description, 4 text columns)
- **Column Widths**: Left logo: 240px | Name: 260px | Description: 360px | Right columns: 160px each
- **Column Width (px)**: Logo area: 240px | Name zone: 260px | Text columns: 160px × 4
- **Gutter Width**: 40px central spine, 20px between right columns
- **Row/Zone Structure**: Header(60px) | Main content(800px) | Text area(500px) | Footer(60px)
- **Baseline Grid**: Typography-focused alignment for systematic text presentation
- **Compound Grid**: Yes - circular element overlay with systematic column text system
- **Confidence**: High
- **Reasoning**: Clear systematic organization with circular emphasis, designer name centerpiece, and structured column text

## 5. Visual Hierarchy
1. **Primary**: Circular "A1" logo element - creates strong visual anchor and brand identity
2. **Secondary**: Large "Willi Kunz" designer name - establishes subject identification
3. **Tertiary**: Left description text - provides biographical and contextual information
4. **Quaternary**: Four-column text system - detailed project and philosophy content
5. **Quintenary**: Vertical "NEW" branding - magazine identity reinforcement
6. **Reading flow**: Circular logo → Designer name → Description → Text columns → Vertical brand

## 6. Spacing & Proportional System
- **Dominant spacing unit**: 40px (margins) and 20px (column gutters)
- **Golden ratio presence**: Strong - spread ratio approaches φ, content positioning follows proportional relationships
- **Vertical rhythm**: Systematic spacing between content zones with consistent 60px header/footer areas
- **Density**: Balanced - dramatic circular element balanced by systematic text organization
- **White space strategy**: High contrast - generous white space on black background emphasizes content hierarchy

## 9. Responsive Adaptation Notes
The systematic column structure and high-contrast aesthetic will face significant challenges on mobile devices. The four-column text system on the right will stack vertically, eliminating the organized information architecture that characterizes professional magazine design. The circular "A1" logo element will lose its spatial relationship to the designer name, breaking the visual hierarchy that establishes brand identity and subject focus. The large "Willi Kunz" name will be compressed, reducing its impact as the primary identification element. Most critically, the sophisticated black and white editorial approach will be simplified to standard mobile text layout, losing the dramatic high-contrast aesthetic that defines the magazine's design sophistication. The vertical "NEW" branding will become horizontal, eliminating the integrated magazine identity approach. The Swiss typography influence that creates systematic information organization will be reduced to sequential content blocks. Consider maintaining the circular logo as a header element and the high contrast color scheme while accepting that the sophisticated multi-column editorial structure will be simplified to single-column mobile format.
