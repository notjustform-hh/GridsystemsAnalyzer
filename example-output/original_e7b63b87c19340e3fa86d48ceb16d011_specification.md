# Layout Specification: Scientific Data Cards - New Horizons Mission

## 1. Format & Proportions
- **Orientation**: Landscape dual-card layout
- **Aspect Ratio**: 2:1 (1200×600px overall)
- **Page Ratio vs φ**: Each card 1:1 square format, overall 2:1 creates strong horizontal emphasis
- **Assumed Format**: Scientific data cards, likely 5"×5" each or digital display format
- **Spread or Single**: Dual-card format with contrasting content approaches

## 2. Margins
- **Top**: 20px (3.3%)
- **Right/Outer**: 20px (1.7% per card)
- **Bottom**: 20px (3.3%)
- **Left/Inner**: 20px (1.7% per card)
- **Gutter**: 40px (3.3%) between cards
- **Symmetry**: Uniform margins with contrasting content organization
- **Notes**: Minimal margins maximize content area for technical data presentation

## 3. Grid System
- **Grid Type**: Scientific data layout (left) paired with typographic emphasis (right)
- **Column Count per Card**: Left: 4-zone data structure | Right: centered typography
- **Total Columns (dual cards)**: 8 zones total across both cards
- **Column Widths**: Left card: varied data zones | Right card: centered 420px typography area
- **Column Width (px)**: Data sections: 140px, 280px, 440px | Typography: 420px centered
- **Gutter Width**: 20px internal spacing, 40px card separation
- **Row/Zone Structure**: Left: image(120px) + coordinates(80px) + specs(200px) + info(80px) | Right: typography(180px) + pattern(140px)
- **Baseline Grid**: Technical precision for scientific data presentation
- **Compound Grid**: Yes - data organization overlaid with typography emphasis
- **Confidence**: High
- **Reasoning**: Clear contrast between analytical data presentation and brand identity expression

## 9. Responsive Adaptation Notes
The dual-card scientific data layout will face significant challenges on mobile devices. The left card's dense technical information - including precise astronomical coordinates, observation arc data, and orbital measurements - will require careful restructuring to maintain scientific accuracy while fitting mobile screens. The systematic data presentation with multiple measurement categories may need to be reorganized into a vertical scrollable format rather than the current zone-based layout. The right card's large "NEW HORIZONS" typography that creates strong brand impact will need scaling that maintains readability without losing visual dominance. The geometric striped pattern that reinforces design identity may become too compressed to be effective on small screens. Most critically, the side-by-side contrast between analytical data and brand identity that defines this design approach will be lost when cards stack vertically on mobile. The scientific precision that requires clear data hierarchy and easy cross-referencing between measurements will be compromised by sequential mobile presentation. Consider creating a mobile version that maintains the technical data integrity through expandable sections while preserving the mission branding through a simplified header design. The geometric patterns could be adapted as subtle background elements rather than dominant visual features.
